# 인사고과 · 개인용

근거로 평가하는 **개인용 인사고과 앱**입니다. 서버 없이 휴대폰 브라우저 안에서 동작하고, 입력한 자료는 그 기기에만 저장됩니다.

- 휴대폰 브라우저로 이 저장소의 GitHub Pages 주소를 열어 씁니다. 처음 한 번 연 뒤로는 인터넷 없이 열립니다.
- 아이폰은 Safari로 연 뒤 [공유] → [홈 화면에 추가]를 하고, 홈 화면 아이콘으로 엽니다.
  Safari와 홈 화면 앱은 저장 공간을 따로 씁니다.
- 근거(확인할 수 있는 자료)를 적은 실적만 KPI 점수에 넣고, 근거가 없는 기록은 따로 표시합니다.
  역량 평가는 날짜와 내용이 있는 사례가 있어야 인정합니다.
- 평가서에 점수·등급과 계산식, 점수에 넣은 기록과 뺀 기록, 산정 규칙이 모두 적힙니다.
- 자료는 어디로도 보내지 않습니다. [자료] 탭에서 백업 파일을 만들어 보관하세요 (홈 화면 아이콘을 지우면 자료도 지워집니다).

이 저장소에는 만들어진 결과물만 있습니다. 원본 코드는 비공개 저장소에서 관리합니다.
