# 인사고과 체험판

KPI 실적 기반 인사고과 관리 시스템을 **서버 없이** 휴대폰 브라우저 안에서 돌리는 체험판입니다.

- 휴대폰 브라우저로 이 저장소의 GitHub Pages 주소를 열고, 홈 화면에 추가해서 씁니다.
- 아이폰은 Safari로 연 뒤 [공유] → [홈 화면에 추가]를 먼저 하고, 홈 화면 아이콘으로 엽니다.
  Safari와 홈 화면 앱은 저장 공간을 따로 쓰기 때문입니다.
- 처음 한 번 앱 파일(약 24MB)을 받은 뒤로는 인터넷 없이 열립니다.
- 입력한 자료는 그 기기의 브라우저 저장소에만 저장되고, 어디로도 보내지 않습니다.
- 들어 있는 직원·평가 자료는 모두 만들어 낸 데모 데이터입니다.

이 저장소에는 만들어진 결과물만 있습니다. 원본 코드는 비공개 저장소에서 관리합니다.
브라우저 안의 파이썬은 [Pyodide](https://pyodide.org) (MPL-2.0)를 씁니다.
